# 전제가 틀린 채 구현이 이어지는 것을 줄이는 검증

새 작업은 `/fun`의 질문 여부와 별개로 명세·테스트·독립 검증을 거칩니다. `/fun`을 꺼도 실행 권한이나 이 검증 단계를 해제하지 않습니다.

## 단계와 중단 기준

| 단계 | 실제로 확인하는 것 | 멈추는 경우 |
| --- | --- | --- |
| 형식 명세 | BDD 전제·입력·반응, 요구사항/테스트 연결, 파일 담당, 선언한 숫자·열거 제약의 교집합 | 빠진 연결·중복 담당·빈 범위·테스트 수정 권한 침범 |
| 독립 설계 챌린지 | 다른 보고서를 보지 않는 읽기 전용 세션 최대 두 개의 전제·위험 검토 | 중대한 지적 하나 또는 서로 다른 두 벤더가 공통 지적한 위험 |
| 테스트 우선 | 실제 러너가 계획한 모든 사례를 실행하고 하나 이상 실패했는지 | 실행·문법·환경 오류, 미실행/건너뛴 사례, 이미 전부 통과한 계획 |
| 구현 | 배정한 파일 범위에서만 수정; 확정 테스트 해시 보존 | 충돌·다른 담당 파일 수정·테스트 변조 |
| 독립 비판 검증 | 구현 후 숨은 전제·권한·경계값·동시성·누락 시나리오 | 근거 있는 중대한 질문 |
| 재검증·순차 리뷰 | 같은 테스트의 Green, 시안 비교(선택), 선택한 리뷰 담당 전체와 최종 컨트롤 타워 검토 | 실패·해결되지 않은 지적·소스 변경·호출/수정 한도 도달 |

질문에는 앱 팝업과 기존 시스템 알림 경로를 사용합니다. 선택지나 직접 입력으로 답할 수 있습니다. 구현 후 전제 질문에서 기존 명세 유지를 선택하면 테스트를 다시 생성하지 않고 검증을 이어갑니다. 요구사항을 바꾸면 같은 작업에서 명세를 새 개정으로 작성합니다.

## 근거와 한계

`Workflow → 전제·명세·테스트 검증`에 각 단계, 지적과 관련 요구사항, 벤더 다양성과 한계를 표시합니다. 버전 있는 형식 명세와 테스트 계획은 승인한 폴더의 `.control-tower/runs/<작업 ID>/`에 저장합니다. `/fun` 명세는 기존 `Function/` 폴더에 개정별로 남깁니다.

검토 결과는 소스와 명세·사용자 답변에 묶습니다. 소스가 같더라도 명세나 결정이 달라지면 독립 검증을 다시 실행합니다. 원본 테스트를 바꾼 뒤 예전 Green이나 체크포인트를 근거로 완료할 수 없습니다.

형식 검사는 제한된 선언의 일관성 검사입니다. 자연어 전제 전체를 증명하거나 테스트가 완벽하다고 보장하지 않습니다. 독립 비판 검증은 별도 세션이며 모델 자체가 구현자와 다를 것까지 보장하지는 않습니다. 같은 벤더만 연결했으면 그 한계를 표시합니다. Cursor에서 GPT/Claude 모델을 쓴 경우 실제 모델 벤더로 구분하고, 알 수 없는 모델을 다른 벤더로 추정하지 않습니다.

## 반복 확인과 사용량

채팅창 `/fun` 옆 자동 수락은 기본 켜짐이지만 규칙은 빈 상태입니다. 취향 질문의 명시적 답변이나 직접 승인한 시안만 기억할 수 있습니다. 현재 OS 사용자·프로젝트·폴더 승인·요청과 질문/명세·시안이 정확히 일치할 때만 재사용합니다. 중요한 검증 질문·새 외부 대상·실행 권한·삭제·예산은 자동으로 답하지 않습니다. 규칙은 같은 자리에서 끄거나 삭제할 수 있습니다.

추가 검증도 작업별/일일 호출·예산·동시 실행 한도에 포함합니다. AI 카드와 컨트롤 타워는 보고된 모델별 토큰과 호출 수를 표시합니다. Workflow에서는 같은 모델의 여러 패널 사용량을 합쳐 비교합니다. 미제공 토큰이나 구독 CLI 금액은 추측하지 않으며 API 단가가 있는 경우만 추정 비용을 표시합니다.

## 검증 방법

`node --test test/engineering-workflow.test.js test/preview-safety.test.js test/engineering-gates.test.js`는 임시 프로젝트에서 실제 Node 테스트의 Red → 구현 → Green, 독립 검토 중단과 재개, 잘못된 보고 거부, 규칙 격리와 승인 변경을 검사합니다. 모델 답변은 명시적인 테스트용 응답입니다. 실제 벤더의 로그인·응답 품질까지 검증했다고 해석하면 안 됩니다. `scripts/check-modern-preview.mjs`는 별도로 실제 React/Vue/Next와 브라우저를 사용하며 검증 후 생성 앱을 삭제합니다.
